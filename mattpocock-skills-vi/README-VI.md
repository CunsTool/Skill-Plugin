## Vị trí giải nén trên Windows

Giải nén ZIP vào `D:\OneDrive\Documents\Skill-AI`. ZIP đã có một thư mục bao ngoài tên `mattpocock-skills-vi`, nên kết quả cần là:

```text

└── mattpocock-skills-vi\
    ├── .claude-plugin\
    │   ├── marketplace.json
    │   └── plugin.json
    ├── .changeset\
    │   └── README.md
    ├── skills\
    │   ├── engineering\
    │   ├── productivity\
    │   ├── misc\
    │   ├── in-progress\
    │   └── deprecated\
    ├── README.md
    ├── README-VI.md
    └── LICENSE
```

Các bộ của tác giả khác đặt cạnh `mattpocock-skills-vi`, trong thư mục `Skill-AI`. Nếu phần mềm giải nén tự tạo thêm một thư mục bọc ngoài, chuyển thư mục `mattpocock-skills-vi` ra đúng vị trí trên. Giữ nguồn cài ở vị trí cố định sau khi đăng ký.

Kiểm tra đường dẫn bằng PowerShell:

```powershell
Test-Path "D:\OneDrive\Documents\Skill-AI\mattpocock-skills-vi\.claude-plugin\marketplace.json"
```

Lệnh cần trả về `True`.

## Cài trong Codex

Cần có Codex CLI và lệnh `codex --version` chạy được trong PowerShell. Sau đó:

```powershell
codex plugin marketplace add "D:\OneDrive\Documents\Skill-AI\mattpocock-skills-vi"
codex plugin add mattpocock-skills-vi@mattpocock-vi
```

Đóng rồi mở lại Codex, tạo chat mới và gõ `$` để kiểm tra danh sách. Ví dụ Ask Matt có công năng “Chọn skill hoặc quy trình phù hợp với công việc”.

Nếu đã đăng ký marketplace `mattpocock-vi` tại đường dẫn cũ, có thể gỡ đăng ký cũ rồi chạy lại hai lệnh cài trên:

```powershell
codex plugin remove mattpocock-skills-vi@mattpocock-vi
codex plugin marketplace remove mattpocock-vi
```

Chỉ dùng hai lệnh gỡ này khi đúng là bạn đã cài/đăng ký tên tương ứng. Gói không tự xóa các skill bạn từng chép thủ công.

## Cài trong Claude Code

Cần có Claude Code và lệnh `claude` chạy được:

```powershell
claude plugin marketplace add "D:\OneDrive\Documents\Skill-AI\mattpocock-skills-vi"
claude plugin install mattpocock-skills-vi@mattpocock-vi
```

Khởi động lại Claude Code. Tên lệnh skill trong plugin có thể kèm namespace plugin. Claude Code dùng phần mô tả trong `SKILL.md` gốc; metadata công năng tiếng Việt trong `agents/openai.yaml` phục vụ Codex.
